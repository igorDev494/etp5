# Objetivo do Software
- O software tem como objetivo principal
otimizar o controle de dados dos clientes e estoque de jogos de pequenas empresas nessa área de forma intuitiva e segura.
Servindo para: Tela de login para funcionários, filtro de pesquisa de jogos, ver pedidos que cliente realizou e a quantidade.

# Funcionalidades do Sistema
- Autenticação de usuários com diferentes níveis de acesso
- Painel visual para exibição de relatórios e gráficos de vendas para cada pedido feito
- Sistema de busca e filtragem avançada de produtos
